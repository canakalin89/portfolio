# Can Akalın | Portfolio

Can Akalın'ın seçili dijital eğitim araçlarını ve kişisel projelerini sergileyen portfolyo sitesi.

Canlı site: https://canhoca.netlify.app/

## Öne Çıkan Projeler

### ChitIQ Codex

Konuşma pratiği ve değerlendirme akışına odaklanan ChitIQ sürümü.

- Uygulama: https://chitiq-codex.vercel.app/
- GitHub: https://github.com/canakalin89/chitiq_codex

### ChitIQ KC

ChitIQ için alternatif arayüz ve kullanım kurgusu sunan sürüm.

- Uygulama: https://chitiq-kc.vercel.app/
- GitHub: https://github.com/canakalin89/chitiq_kc

### Gelişim Raporu Asistanı

E-Okul gelişim raporu formlarını hızlıca doldurmaya yardımcı olan Chrome uzantısı.

- Chrome Web Store: https://chromewebstore.google.com/detail/geli%C5%9Fim-raporu-asistan%C4%B1/ljcjidfmpfnilniagebhccolaidkpogb
- GitHub: https://github.com/canakalin89/gelisim-raporu-asistani

### Atatürk İlke ve İnkılapları Panosu

Okul ekranları için hazırlanmış interaktif dijital pano.

- Uygulama: https://ata1923.netlify.app
- GitHub: https://github.com/canakalin89/ata_pano

## Teknolojiler

- React 19
- TypeScript
- Vite
- Tailwind CSS CDN

## Yerel Çalıştırma

Gereksinim: Node.js

```bash
npm install
npm run dev
```

## Üretim Derlemesi

```bash
npm run build
```

## Notlar

- Site Netlify üzerinde yayındadır.
- Ana proje listesi `App.tsx` içinde tutulur.
- Tasarım koyu temalı, kart tabanlı bir proje vitrini olarak düzenlenmiştir.
