# Can Akalın | Portfolio

Kişisel portfolyo sitesi. React + TypeScript + Vite ile geliştirilmiştir.

Canlı site: https://canhoca.netlify.app/

## Teknolojiler

- React 19 + TypeScript
- Vite
- Tailwind CSS (CDN)

## Yerel Çalıştırma

**Gereksinimler:** Node.js

1. Bağımlılıkları yükle:
   ```bash
   npm install
   ```

2. Geliştirme sunucusunu başlat:
   ```bash
   npm run dev
   ```
