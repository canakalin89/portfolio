# Can Akalın | Portfolio

Kişisel portfolyo sitem. React + TypeScript + Vite ile geliştirilmiştir.

## Teknolojiler

- React 19 + TypeScript
- Vite
- Tailwind CSS (CDN)

## Yerel Çalıştırma

**Gereksinimler:** Node.js

1. Bağımlılıkları yükle:
   ```bash
   npm install
   ```

2. Geliştirme sunucusunu başlat:
   ```bash
   npm run dev
   ```
